# 🧮 Matematicos

**Matematicos** es una librería modular en **Java** diseñada para facilitar el cálculo matemático, algebraico, geométrico y científico. La aplicación está estructurada con **Maven** y organizada en paquetes especializados para un código limpio, reutilizable y fácil de mantener.

---

## 🚀 Características y Funcionalidades

El proyecto incluye módulos específicos para distintas áreas matemáticas:

- **`Geometria2D` y `Geometria3D`**: Métodos para el cálculo de distancias euclídeas, puntos medios, pendientes de rectas, áreas y volúmenes de figuras geométricas.
- **`Punto2D`**: Clase modelo para la representación y manipulación de coordenadas en el plano cartesiano ($x, y$).
- **`Algebra`**: Operaciones algebraicas avanzadas, resolución de ecuaciones y manipulación de expresiones.
- **`Matrices`**: Utilidades para operaciones matriciales (suma, multiplicación, determinantes, etc.).
- **`Induccion`**: Algoritmos orientados a pruebas por inducción matemática y secuencias.
- **`FisicaQuimica`**: Definición de constantes y fórmulas aplicadas a las ciencias físicas y químicas.
